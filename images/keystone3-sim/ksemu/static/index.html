El reset borra el PIN, los ajustes y la billetera que el dispositivo tenga guardada en su memoria interna. Los archivos de la MicroSD no se tocan.

¿De dónde saco estos archivos?

PSBT. Lo exporta tu billetera al armar un pago desde una cuenta de solo lectura (en Sparrow: Send → Create Transaction → Save Transaction; también Nunchuk, Electrum o Blue Wallet). Sirve tanto el .psbt binario como el mismo contenido en base64.

La MicroSD casi no firma. Con una billetera de una sola firma el dispositivo firma solo por QR: la opción Firmar desde la tarjeta Micro SD del menú … aparece únicamente cuando la billetera activa es multifirma. La tarjeta sirve además para importar y exportar una configuración multifirma y para exportar el archivo de conexión con tu billetera de software.

Otros QR. Cualquier archivo de texto se entrega tal cual, una línea por QR: sirve para los ur: que muestran las billeteras de software al conectarse.

La seed se tipea, no se escanea. Para importar una billetera, el dispositivo pide las 12 o 24 palabras en su propio teclado (con autocompletado: alcanzan las primeras letras). En la MicroSD te dejamos un ejemplo-seed-publica.txt con la seed de prueba más conocida que existe.

Cómo los subís. Abrí Archivos (MicroSD) arriba a la derecha y arrastrá el archivo ahí, o usá el botón + → New file del explorador para escribir sin salir del navegador.

Esto es un simulador, no un Keystone. El PIN y las palabras anti-phishing no protegen nada: acá el secure element es un archivo en tu Umbrel, sin cifrar. Y el generador de aleatoriedad del hardware está simulado, así que una billetera creada dentro del simulador es predecible: importá una seed de prueba, nunca uses una que tenga fondos ni te lleves al mundo real una seed nacida acá.
